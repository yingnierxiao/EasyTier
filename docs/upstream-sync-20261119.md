及命令行 `--bind-address` 名称保持不变，已有文本配置无需改名。

旧 fork 二进制使用的 protobuf 编号与上游发生冲突，因此不能把旧编号作为新字段别名继续
接受。使用 protobuf 管理协议并需要读写源地址绑定的客户端和服务端应一起升级；不要
把新旧 fork 二进制混用视为已验证兼容。备份分支保留旧二进制对应的完整源代码。

新增协议测试同时编码上游 FEC/DNS 字段与本地源地址字段，验证不会串字段或解码失败，
并验证 JSON 配置名称保持一致。
